计算 pair 的哈希值。

参数
p待哈希的 pair
返回
混合后的哈希值

混合公式： \(h = \mathrm{splitmix64}(h_1 \oplus (h_2 + c + (h_1 \ll 6) + (h_1 \gg 2)))\)， 其中 \(c = 0x9e3779b97f4a7c15\)， \(h_1 = \mathrm{splitmix64}(\mathrm{hash}(A) + c)\)， \(h_2 = \mathrm{hash}(B)\)。
