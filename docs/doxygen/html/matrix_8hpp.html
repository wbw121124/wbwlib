wbwlib/core/base.hpp

用法（配合 modint）： using M = wbwlib::math::modint<1000000007>; wbwlib::math::Mat<M> A(2, 2); A(0,1) = M(1); ... Mat<M> C = A * A.pow(k);

注意
复杂乘法可针对性优化（如 += 合并），OI 场景已足够。
