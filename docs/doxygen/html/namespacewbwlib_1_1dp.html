决策单调性分治 DP： \(dp_j[i] = \min_{p < i}\{dp_{j-1}[p] + cost(p+1, i)\}\)。

模板参数
Cost代价函数类型，cost(l, r) 返回区间 [l, r] 的代价。
参数
n状态数（i 取值范围 [1, n]）。
KDP 层数。
cost代价函数，需满足四边形不等式以保证最优决策点随 i 单调不减。
返回
长度为 n+1 的数组，ans[i] = dp[K][i]（i >= 1）。

◆ tsp()

i64 wbwlib::dp::tsp ( const std::vector< std::vector< i64 >> &  dist)
inline

旅行商模板：完全图上从顶点 0 出发并回到 0 的最短哈密顿回路。

状态转移： \(dp[S][j] = \min_{i \in S, i \neq j}\{dp[S \setminus \{j\}][i] + dist[i][j]\}\)。

参数
distn×n 距离矩阵，dist[i][j] 为 i → j 的距离（i, j ∈ [0, n)）。
返回
最短回路总代价；不可达视为 INF。 例： std::vector<std::vector<i64>> d(n, std::vector<i64>(n)); i64 ans = wbwlib::dp::tsp(d);
