详细描述

大步小步法 Baby-Step-Giant-Step：解离散对数 a^x ≡ b (mod p)。

依赖
wbwlib/core/base.hpp, wbwlib/math/number-theory.hpp
复杂度
O(sqrt(p)) 时间与空间（哈希表）。

要求 gcd(a, p) == 1（返回 -1 表示无解）。求最小非负 x。

示例
long long x = wbwlib::math::bsgs(a, b, p);
