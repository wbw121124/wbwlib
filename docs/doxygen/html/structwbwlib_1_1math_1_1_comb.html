详细描述

template<class M>
struct wbwlib::math::Comb< M >

组合数学预计算结构体：阶乘与阶乘逆元，O(1) 查询组合数/排列数。

用法： using M = modint<1'000'000'007>; Comb<M> cb(100000); // 预计算 0..100000 的阶乘 M v = cb.C(10, 3); // 组合数 C(10,3)=120 M p = cb.P(10, 3); // 排列数 10*9*8

复杂度：构造 O(n)，单次查询 O(1)。

模板参数
M模整数类（wbwlib::math::modint<MOD> 或 modint_dyn）
