template<u64 MOD, typename Base = i64>
class wbwlib::math::modint< MOD, Base >

固定模数的模整数类：所有运算自动取模，支持与原生整数混合运算。

模板参数
MOD编译期模数（> 0）
Base底层整数类型，默认 i64
