template<class T = i64>
class wbwlib::ds::Splay< T >

伸展树 Splay（序列模式，文艺平衡树）：按位置维护序列。

支持区间翻转、区间加、区间和、按位置插入/删除；单次操作均摊 O(log n)。

模板参数
T元素类型（默认 i64）
