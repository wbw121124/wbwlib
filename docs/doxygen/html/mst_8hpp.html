详细描述

最小生成树：Kruskal（并查集）+ Prim（堆）。

依赖
wbwlib/core/base.hpp、wbwlib/graph/adjacency.hpp
复杂度
Kruskal O(E log E)，Prim O(E log V)。

返回 MstResult{ total, edges, ok }；不连通则 ok=false。
