class wbwlib::ds::segment_tree< Tval, Ttag, pushup, addtag, hastag, merge, nullval, compose_tag >

泛型懒标记线段树（递归实现，4n 空间）：策略全部固化在模板参数中。

函数指针模板参数（pushup/addtag/hastag/merge/nullval/compose_tag）说明见文件头， 默认组合为「区间加 + 区间和」。

模板参数
Tval节点聚合值类型（默认 i64）
Ttag懒标记类型（默认 i64；约定 Ttag() 为空标记）
