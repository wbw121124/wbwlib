template<class T, class Op>
class wbwlib::ds::SparseTable< T, Op >

Sparse Table（ST 表）：静态区间幂等查询（min/max/gcd/…），查询 O(1)。

要求 op 为幂等半群运算： \(op(op(a,b),b) = op(a,b)\)；区间和不可用。

模板参数
T元素类型
Op幂等半群运算类型
