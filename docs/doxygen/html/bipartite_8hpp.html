详细描述

二分图判定（黑白染色）+ 最大匹配（匈牙利）+ 最小点覆盖/最大独立集。

依赖
wbwlib/core/base.hpp、wbwlib/graph/adjacency.hpp

复杂度： 染色 O(V+E)；匈牙利 O(VE)。

用法（左部 1..nL，右部 1..nR，逻辑编号）： std::vector<int> matchR = max_matching(nL, nR, adjL); // matchR[v]=左点，0=未匹配
