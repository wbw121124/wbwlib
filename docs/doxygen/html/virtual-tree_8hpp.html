详细描述

虚树：保留关键点及其两两 LCA，压缩成 O(k) 规模的树。

依赖
wbwlib/core/base.hpp、wbwlib/graph/lca.hpp
复杂度
O(k log n)。
示例
wbwlib::graph::VirtualTree vt(lc); // lc 为已建好的 LCA（含 dfn）
vt.build(keys); // keys 为 1 基点集
vt.edges // (u,v) 原始编号边列表
vt.nodes // 虚树包含点的原始编号
