详细描述

笛卡尔树：中序遍历为原序列、满足堆性质的二叉树。

依赖
wbwlib/core/base.hpp
复杂度
O(n)（单调栈）。
示例
构建小根笛卡尔树（值越小越接近根）：
auto [root, l, r] = wbwlib::ds::cartesian_tree(a, false);
// l[i], r[i] 为 i 的左右孩子（0 表示无）；root 为根
