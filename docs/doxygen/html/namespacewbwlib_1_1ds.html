多询问莫队：离线处理若干静态区间查询（元素可加可删）。

排序采用奇偶优化；复杂度 \(O((n + q) \sqrt{n})\) 次 add/del。

模板参数
AddF添加函数类型（接收元素下标 idx）
DelF删除函数类型（接收元素下标 idx）
GetF求当前答案的函数类型（无参，返回答案）
参数
qs询问集合（1 基闭区间 [l, r]）
add添加下标 idx 对应的元素后更新状态
del删除下标 idx 对应的元素后更新状态
get返回当前区间对应的答案
n序列长度（下标范围 [1, n]）
返回
与 qs 顺序一一对应的答案数组

◆ lf

template<class T = i64, i64 XLO = 1, i64 XHI = 1000000, class Cmp = std::greater<void>, int PoolN = 1 << 20>
bool wbwlib::ds::lf = nw_lt(seg_[id], nw, L)

李超线段树：维护直线族 \(y = k \cdot x + b\) 的最值查询。

支持在值域 \([XLO, XHI]\) 上插入直线、单点查询最优值。 Cmp 取 std::greater 求最大值，取 std::less 求最小值。

模板参数
T系数与值的类型（默认 i64）
XLO值域左端点（含）
XHI值域右端点（含）
Cmp最值比较器
PoolN静态数组池大小（满二叉索引，需覆盖值域节点数）
