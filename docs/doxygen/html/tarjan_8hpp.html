详细描述

强连通分量 / 割点 / 桥（Tarjan）。

依赖
wbwlib/core/base.hpp、wbwlib/graph/adjacency.hpp
复杂度
O(V+E)。
示例
int scc_cnt = tarjan_scc(g, scc_id); // scc_id[1..n]，从 1 编号
vector<int> is_cut = tarjan_cut(g); // 0/1
vector<pair<int,int>> bri; tarjan_bridge(g, bri); // 桥（u<v）
