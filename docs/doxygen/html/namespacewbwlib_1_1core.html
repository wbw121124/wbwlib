将序列 a 离散化（坐标压缩），返回每个 a[i] 对应的 0 基排名。

排名公式： \(r_i = |\{j : x_j < a_i\}|\)，其中 \(x\) 为 a 去重排序后的序列。

模板参数
T元素类型（需支持 < 比较）
参数
a原序列
返回
与 a 等长的排名序列（值域为 0..去重后个数-1）
