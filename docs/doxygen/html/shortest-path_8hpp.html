详细描述

最短路：Dijkstra（堆）/ SPFA（判负环）/ Floyd / 0-1 BFS / 拓扑序 DAG。

依赖
wbwlib/core/base.hpp、wbwlib/graph/adjacency.hpp

复杂度： dijkstra O((V+E) log V)，要求边权非负。 spfa O(VE) 最坏，可判负环；返回 false 表示存在负环。 floyd O(V^3)，任意两点最短路（INF= 不存在）。 bfs01 O(V+E)，边权 ∈ {0,1}。 dag_shortest O(V+E)，DAG 最短路/最长路（先拓扑序再 DP）。
