template<class T = i64, bool UseMax = true>
class wbwlib::ds::LazySeg< T, UseMax >

递归懒标记线段树：区间加 / 区间赋值 + 区间和 / 区间最大值。

模板参数
T元素类型（默认 i64）
UseMax是否维护区间最大值（true 维护 sum 与 mx，false 仅维护 sum）
