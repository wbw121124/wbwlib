详细描述

template<class Char = char, int ALPHA = 26, class CharMap = LowerCharMap>
class wbwlib::str::PAM< Char, ALPHA, CharMap >

回文自动机（回文树）PAM：每个节点代表一个本质不同的回文串。

节点 0 为奇根（len = -1），节点 1 为偶根（len = 0）。

模板参数
Char字符类型（默认 char）
ALPHA字母表大小（默认 26）
CharMap字符映射策略（默认小写字母 LowerCharMap）
