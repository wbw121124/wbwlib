详细描述

template<class Char = char, int ALPHA = 26, class CharMap = LowerCharMap>
class wbwlib::str::Trie< Char, ALPHA, CharMap >

模板化字典树：字符类型、字母表大小、字符映射均可自定义。

模板参数
Char字符类型（默认 char）
ALPHA字母表大小（默认 26）
CharMap字符映射策略：静态 id(char)->[0,ALPHA)，静态 valid(char)->bool（默认小写字母）
