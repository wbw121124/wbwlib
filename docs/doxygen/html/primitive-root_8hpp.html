详细描述

原根求解：求模 p 意义下的最小原根（常用 NTT 前置，p 为质数）。

依赖
wbwlib/core/base.hpp, wbwlib/math/number-theory.hpp, wbwlib/math/primes.hpp

原理：g 是模 p 的原根 ⇔ ord(g) = p-1 ⇔ 对所有 p-1 的质因子 q，g^((p-1)/q) != 1。

复杂度
O(sqrt(p) · ω(p) · log p)，实际枚举 g 很小。
