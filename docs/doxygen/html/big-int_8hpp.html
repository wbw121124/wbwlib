详细描述

高精度整数：十进制 1e9 基（符号 + 幅值）。

依赖
wbwlib/core/base.hpp

设施：构造（字符串/i64/拷贝）、比较、+ - * / （被 BigInt 或 i64）、 幂 pow、to_string、流输出。常规竞赛规模（≤ 1e5 位以内）够用。

示例
wbwlib::misc::BigInt a("12345678901234567890"), b(12345);
auto c = a * b;
std::cout << c / b << "\n";
