template<class Char = char, int ALPHA = 26, class CharMap = LowerCharMap>
class wbwlib::str::SAM< Char, ALPHA, CharMap >

后缀自动机 SAM：线性构建，支持本质不同子串数、子串出现次数等查询。

模板参数
Char字符类型（默认 char）
ALPHA字母表大小（默认 26）
CharMap字符映射策略（默认小写字母 LowerCharMap）
