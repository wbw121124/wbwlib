template<u64 MOD1 = 1000000007ULL, u64 MOD2 = 1000000009ULL>
class wbwlib::str::StringHash< MOD1, MOD2 >

字符串双哈希：模数模板化（默认 1e9+7 / 1e9+9），预处理 O(n) 后子串哈希 O(1)。

模板参数
MOD1第一路模数（默认 1000000007）
MOD2第二路模数（默认 1000000009）
