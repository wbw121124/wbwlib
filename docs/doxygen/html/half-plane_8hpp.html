详细描述

半平面交：极角排序 + 双端队列（实数版）。

依赖
wbwlib/core/base.hpp、wbwlib/geo/point.hpp
复杂度
O(n log n)。

HalfPlane{ a, b } 语义：有向直线 a→b 左侧（含）为可行侧。 intersect() 返回可行多边形顶点（逆时针）；空返回空 vector。
