详细描述

template<class T = i64>
class wbwlib::ds::PersistentSegTree< T >

可持久化线段树（主席树）：版本化点更新 + 两版本差值的区间查询。

每次 update 生成新版本根；两版本对应位置的差即历史区间内元素的累计变化， 典型用于静态区间第 k 小/大。

模板参数
T节点聚合值类型（默认 i64），需支持 += 与 -=。
