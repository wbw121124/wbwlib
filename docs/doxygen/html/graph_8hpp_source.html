adjacency.hpp
图表示约定：1 基邻接表 + 常用辅助。
bipartite.hpp
二分图判定（黑白染色）+ 最大匹配（匈牙利）+ 最小点覆盖/最大独立集。
euler-path.hpp
欧拉路径 / 欧拉回路（Hierholzer，有向/无向）。
hld.hpp
树链剖分（HLD）：剖分 + 路径/子树区间映射，供线段树等配合。
lca.hpp
LCA：倍增法（O(n log n) 预处理，O(log n) 查询）+ 树深/距离/第 k 祖先。
link-cut-tree.hpp
动态树 LCT：link/cut/makeroot/findroot/路径和查询/路径加/点权修改。
min-cost-flow.hpp
最小费用最大流：SPFA 增广（允许负费用边，判负环场景另处理）。
mst.hpp
最小生成树：Kruskal（并查集）+ Prim（堆）。
network-flow.hpp
最大流：Dinic（当前弧优化 + 分层）。
shortest-path.hpp
最短路：Dijkstra（堆）/ SPFA（判负环）/ Floyd / 0-1 BFS / 拓扑序 DAG。
tarjan.hpp
强连通分量 / 割点 / 桥（Tarjan）。
topo.hpp
拓扑排序（Kahn，返回字典序可选）+ 判环 + 关键路径。
tree-dp.hpp
树上 DP 套路：直径、中心、换根 DP 模板。
virtual-tree.hpp
虚树：保留关键点及其两两 LCA，压缩成 O(k) 规模的树。
