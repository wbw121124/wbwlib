template<class Char = char, int ALPHA = 26, class CharMap = LowerCharMap>
class wbwlib::str::ACAutomaton< Char, ALPHA, CharMap >

AC 自动机：多模式匹配，构建 fail 指针后线性扫描文本统计模式出现。

模板参数
Char字符类型（默认 char）
ALPHA字母表大小（默认 26）
CharMap字符映射策略（默认小写字母 LowerCharMap）
