详细描述

欧拉路径 / 欧拉回路（Hierholzer，有向/无向）。

依赖
wbwlib/core/base.hpp、wbwlib/graph/adjacency.hpp
复杂度
O(V+E)。

用法（无向图，图需本身连通）： std::vector<int> path; bool ok = euler_undirected(g, path); // path 为顶点序列（若存在） 有向图： bool ok = euler_directed(g, path);

说明：实现为删边式 Hierholzer（边用 multiset 模拟删除）。
