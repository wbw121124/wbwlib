详细描述

单调栈、单调队列（滑动窗口最值）、最近小/大元素。

依赖
wbwlib/core/base.hpp
复杂度
均为线性 O(n)。
示例
// 对每个位置求左侧最近的严格更小元素下标（1..n），无则 0
auto lt = wbwlib::ds::prev_smaller(a);
// 滑动窗口最小值（窗口长度 k，返回每个窗口的最小值序列）
auto mn = wbwlib::ds::sliding_window_min(a, k);
