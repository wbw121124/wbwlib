◆ reroot_dp()

template<class T , class Merge , class Push >
std::vector<T> wbwlib::graph::reroot_dp ( int  n,
const Adj &  g,
int  root,
T  identity,
Merge  merge,
Push  push 
)

换根 DP 通用模板：以每个点作根求整树聚合值。

内部：第一次 DFS 挂树并求 dp[u] = merge(所有子树)；第二次 DFS 沿 down 传递父侧贡献， 用前后缀 O(1) 剔除单条子树。

模板参数
T聚合值类型
Merge可结合的聚合函数（merge(a, b)，顺序固定）
Push父侧贡献推给子树的函数（push(up, u, v)）
参数
n点数（1 基）
g树的无权邻接表
root首次 DFS 的根（1 基）
identity聚合单位元（如 0）
merge子树贡献合并函数
push由「u 侧除 v 分支外的整树贡献」推出发给子树 v 的贡献
返回
f[u]：以 u 为根的整棵树聚合值
