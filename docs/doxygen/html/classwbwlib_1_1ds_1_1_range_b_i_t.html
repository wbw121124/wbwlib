详细描述

template<class T = i64>
class wbwlib::ds::RangeBIT< T >

区间加 + 区间和的差分树状数组（双 BIT）。

add(l, r, v)： \(a[l..r]\) 整体加 v；range_sum(l, r)：查询区间和。

模板参数
T元素类型（默认 i64），需支持 +=、-= 与乘法。
