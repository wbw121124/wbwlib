详细描述

Sparse Table ST 表：静态区间幂等查询（取 min/max/gcd/…），O(1) 查询。

依赖
wbwlib/core/base.hpp
复杂度
预处理 O(n log n)，查询 O(1)。 限制：仅适用于「幂等半群」（联合两次不影响结果），即要求 f(f(a,b),b)=f(a,b)， 区间最值、gcd、位与、位或均适用；区间和不可用（请用线段树/前缀和）。
示例
wbwlib::ds::SparseTable<i64> st(a, [](i64 x, i64 y){ return std::min(x, y); });
i64 ans = st.query(l, r); // 1 基
