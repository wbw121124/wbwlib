详细描述

LCA：倍增法（O(n log n) 预处理，O(log n) 查询）+ 树深/距离/第 k 祖先。

依赖
wbwlib/core/base.hpp、wbwlib/graph/adjacency.hpp
示例
wbwlib::graph::LCA lc(g, 1); // g 为树的邻接表（无向）
int w = lc.query(u, v);
int k = lc.kth(u, k); // u 向上第 k 个祖先（k>=1）
i64 d = lc.dist(u, v); // 需要边权时用 WeightedLCA
