详细描述

后缀数组：倍增 + 计数排序构造，附 rank、height（LCP）数组。

结果（0 基字符串 s，长度 n）： sa[1..n] 第 i 小的后缀的起始位置（0 基），sa[0] 恒为 0 未使用； rank[i] 起始位置 i 的后缀排名（1 基）； height[1..n] height[i] = LCP(sa[i-1], sa[i])，height[1] = 0。
