并查集。

无旋转 Treap（FHQ Treap）。

li-chao-tree.hpp
李超线段树：维护直线族 y = k*x + b 的最值查询。

莫队算法：离线处理静态区间查询（可加分可删）。
monotonic.hpp
单调栈、单调队列（滑动窗口最值）、最近小/大元素。
persistent-segtree.hpp
可持久化线段树（主席树）：静态区间第 K 小/大、版本化点更新。
segment_tree.hpp
泛型懒标记线段树（Tval 值类型 / Ttag 标记类型，策略全在模板参数）。
segtree-beats.hpp
吉司机线段树（Segment Tree Beats）：区间取 min / 区间加 / 区间和、区间最大值。
segtree.hpp

sparse-table.hpp

splay.hpp
伸展树 Splay（序列模式，文艺平衡树）。
sqrt-block.hpp
