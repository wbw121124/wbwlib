详细描述

快速沃尔什变换 FWT：集合幂级数的 OR / AND / XOR 卷积。

依赖
wbwlib/core/base.hpp, wbwlib/math/modular.hpp
复杂度
每维 O(n log n)。

using M = wbwlib::math::modint<998244353>;
std::vector<M> a(n), b(n);
std::vector<M> c = wbwlib::math::convolution_xor(a, b); // 或 _or/_and
