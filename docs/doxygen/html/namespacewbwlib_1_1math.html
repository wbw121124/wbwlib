◆ bsgs()

i64 wbwlib::math::bsgs ( i64  a,
i64  b,
i64  p 
)
inline

大步小步法（BSGS）：解离散对数 \(a^x \equiv b \pmod p\)。

要求 \(\gcd(a, p) = 1\)。取 \(m = \lceil \sqrt p \rceil\)，枚举小步 \(b a^j\) 与大步 \(a^{im}\)， 复杂度 \(O(\sqrt p)\) 时间与空间。

参数
a底数
b目标值
p模数（与 a 互质）
返回
满足同余式的最小非负 \(x\)；无解返回 -1

double  fp_eps = 1e-9 
)

对增广矩阵 a（n 行 × (m+1) 列，最后一列为常数列）做高斯消元，返回秩。

  • 算术类型（int/double 等）：绝对值部分主元消元，稳定性好；
  • 自定义类型（如 modint）：精确首非零主元消元。

消元后矩阵化为行最简形（主元列单位化、其余行消为 0）。

模板参数
T元素类型（需支持 0、1、+、-、*、/、==）
