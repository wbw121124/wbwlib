详细描述

图表示约定：1 基邻接表 + 常用辅助。

依赖
wbwlib/core/base.hpp

约定：

  • 所有图算法使用 1..n 的点编号。
  • 无权图：Adj = vector<vector<int>>（大小为 n+1）。
  • 带权图：WAdj<W> 结构体（成员 g[n+1]，pair(v,w)）。
  • 树：同上，通常建双向边。
