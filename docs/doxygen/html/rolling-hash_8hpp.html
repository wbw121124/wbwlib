字符串双哈希（模板化双模数），取模 + 自然溢出可选。

依赖
wbwlib/core/base.hpp
复杂度
预处理 O(n)，子串哈希 O(1)。
示例
wbwlib::str::StringHash<> hs(s, 131); // 默认 1e9+7 / 1e9+9
if (hs.sub(l1, r1) == hs.sub(l2, r2)) ... // l,r 为 1 基
wbwlib::str::StringHash<998244353ULL, 1000000007ULL> hs2(s); // 自定义双模数
