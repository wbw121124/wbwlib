详细描述

树状数组 Fenwick：单点加 + 区间和；RangeBIT 区间加 + 区间和；二维 BIT。

依赖
wbwlib/core/base.hpp
复杂度
单次操作 O(log n)（2D 为 O(log^2 n)）。 下标约定：1 基（BIT[1..n]）。
示例
wbwlib::ds::Fenwick<long long> bit(n);
bit.add(3, 5); bit.range_sum(1, 10);
