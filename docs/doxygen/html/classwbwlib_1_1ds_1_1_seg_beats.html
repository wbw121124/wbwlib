template<class T = i64>
class wbwlib::ds::SegBeats< T >

吉司机线段树（Segment Tree Beats）：区间取 min、区间加、区间和、区间最大值。

取 min 操作均摊复杂度 \(O(\log^2 n)\)。

模板参数
T元素类型（默认 i64）
